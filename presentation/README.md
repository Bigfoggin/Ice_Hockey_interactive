# Presentation

Pitch für die Sport Innovation Challenge 2026, 7 Folien auf Englisch, gegliedert nach den vier Kriterien (Problem and user need · Concept and interaction · Data, feasibility and impact · Activation).

- `Hockey-verstehen-Pitch-EN.pptx`: editierbar, mit Sprechernotizen
- `Hockey-verstehen-Pitch-EN.pdf`: zum Verschicken
- `img/`: Screenshots für die Folien
- `slides/`: Generator (pptxgenjs) und Hintergrundbilder, nur nötig, um die Folien neu zu erzeugen. Für Änderungen direkt in PowerPoint arbeiten.
