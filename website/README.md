# Website

Landing Page, die beide Angebote nebeneinander vorstellt. Sie verlinkt nur, der Code der Angebote bleibt in den eigenen Ordnern:

- **Be a Pro** → `../index.html` (Pass-Spiel, betreut von deiccoalessi)
- **Learn the Game** → `../learn_the_game/Hockey-verstehen.html`

Öffnen: `website/index.html` im Browser. Das Handy im Abschnitt «Probier es aus» zeigt Learn the Game, sobald `Hockey-verstehen.html` lokal erzeugt wurde (siehe `learn_the_game/README.md`).

Mit `index.html?static` werden alle Inhalte ohne Animation angezeigt (für Screenshots).
